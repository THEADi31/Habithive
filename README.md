# HabitHive

A habit tracker built to practise every topic from the Flutter and Dart course.
Light and dark themes (plus Auto), local storage, an API call, named routes and Provider state.

## 1. Set up (once)

1. Install the Flutter SDK (docs.flutter.dev/get-started/install) and Android Studio.
2. `flutter doctor --android-licenses`, then `flutter doctor` and fix anything red.

## 2. Turn this folder into a full project

This folder holds the Dart code (`lib/`), `pubspec.yaml` and a test. The Android and iOS
platform folders are generated by Flutter. Open a terminal inside this folder and run:

```
flutter create --project-name habit_hive .
flutter pub get
```

`flutter create .` only adds missing files (android/, ios/, web/ ...). If it ever replaces
`lib/main.dart`, copy it again from the original zip.

If `pub get` reports a version conflict, run `flutter pub upgrade --major-versions`.

## 3. Run on your phone

1. Phone: Settings > About phone > tap Build number 7 times, then Settings > Developer options > USB debugging ON.
2. Plug in the USB cable and tap Allow on the phone.
3. `flutter devices` should list your phone, then run `flutter run`.
   Press `r` for hot reload, `R` for hot restart, `q` to quit.

## 4. Install a release APK

1. Open `android/app/src/main/AndroidManifest.xml` and add this line just above `<application`:

   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   ```
2. `flutter build apk --release`
3. APK location: `build/app/outputs/flutter-apk/app-release.apk`
4. Copy it to your phone and open it (allow "Install unknown apps" if asked), or run `flutter install`.

## Folder map

```
lib/
  main.dart                  loads saved data, then runApp with MultiProvider
  app.dart                   MaterialApp: light theme, dark theme, themeMode
  routes.dart                named routes (/, /habit, /habit/form)
  theme/app_theme.dart       bright + dark ColorScheme from one seed colour
  models/habit.dart          Habit class, streak logic, JSON
  utils/date_helpers.dart    extension methods on DateTime
  services/
    storage_service.dart     shared_preferences (habits + theme choice)
    quote_service.dart       http API call with offline fallback
    analytics_service.dart   stand-in for Firebase / Google Analytics
  providers/
    habit_provider.dart      ChangeNotifier for habits
    settings_provider.dart   ChangeNotifier for theme mode
  screens/
    home_shell.dart          AppBar, NavigationBar, FAB, quick theme toggle
    today_screen.dart        progress ring, quote, habit list
    habit_detail_screen.dart streaks, 5-week grid, edit/delete
    habit_form_screen.dart   Form with validation, icon and colour pickers
    stats_screen.dart        weekly bar chart, 30-day rates
    settings_screen.dart     Light/Dark/Auto, reset data, about
  widgets/                   progress_ring, habit_tile, quote_card, heat_grid, stat_card
test/habit_test.dart         unit tests (streaks, JSON)
```

Run the tests with `flutter test`.
